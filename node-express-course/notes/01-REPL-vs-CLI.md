# REPL vs CLI

## REPL (Read-Eval-Print Loop)
- An interactive environment that executes code line by line.
- Reads input, evaluates it, prints output, and repeats.
- Used for testing and experimenting with code.
- Example: Node.js REPL (`node`).

## CLI (Command-Line Interface)
- A text-based interface to interact with the operating system or applications.
- Executes commands entered by the user.
- Used for file management, running programs, and system operations.
- Example: Linux Terminal.

## Key Differences

| REPL | CLI |
|---|---|
| Executes code interactively | Executes commands |
| Mainly used for testing code | Used for system operations |
| Evaluates expressions directly | Accepts command-line instructions |
| Example: Node.js REPL | Example: Bash |
